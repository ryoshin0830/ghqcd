# 0.2.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship PR #1's one search window as 0.2.0, with the second review's remaining findings fixed.

**Architecture:** Unchanged from the PoC (CLAUDE.md I12). Every fix is a few lines in the module that owns it; each gets one regression test.

**Tech Stack:** Node ≥ 20.12 ESM, `node:test`, ghq, fzf, git. No runtime dependency.

**Spec:** `docs/superpowers/specs/2026-10-27-release-0.2-design.md` (finding numbers refer to PR #1's second review).

## Global Constraints

- CLAUDE.md I1–I12 hold. stdout is machine output only; `--json` shape unchanged (I7).
- No runtime dependency, no install script (I9, Do NOT).
- Tests: no network, no TTY, never the developer's own cache or `gh` login.
- No commit message line may carry the CI skip token.

## Review Focus

- A cache dir whose path is long (> ~100 bytes): the window must still open (Task 5 test).
- A query starting with `-` typed in the window: results, not a parseArgs error (Task 5 test).
- A truncated `~/.cache/ghqcd/index.json`: `ghqcd api` still lands, `--index` repairs it (Task 4 test).
- An agent following SKILL.md: `--list --json <q>` shows the same candidates `--json <q>` counted (Task 3 test).
- A clone whose path case differs from GitHub's (`Alice/Tools` vs `alice/tools`): one line, cloned (Task 4 test).
